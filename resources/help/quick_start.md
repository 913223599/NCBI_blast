# 快速入门指南

欢迎使用 NCBI BLAST Pro 生物序列分析工作站。本指南将帮助您快速上手使用本软件的核心功能。

## 1. 界面概览

软件主界面分为三个主要区域：
- **左侧侧边栏**：包含文件选择和参数设置。
- **右侧工作区**：包含控制面板（顶部）和结果查看器（主体）。
- **顶部菜单栏**：提供更多高级功能入口，如历史记录、数据库管理等。

## 2. 运行您的第一个 BLAST 任务

### 第一步：选择序列文件
1. 在左侧“文件选择”区域，点击“浏览”按钮或直接拖拽文件。
2. 支持 `.fasta`, `.txt` 等常见序列格式。
3. 选中文件后，它们会显示在列表中。

### 第二步：设置参数
1. 在左侧“参数设置”区域，选择 BLAST 程序类型（如 `blastn`, `blastp` 等）。
2. 选择目标数据库（如 `nt`, `nr`）。
   - 如果没有本地数据库，请先通过“设置”->“本地数据库管理”进行下载或构建。
3. 根据需要调整 E-value 阈值和线程数。

### 第三步：开始分析
1. 点击右侧顶部的“开始处理”按钮。
2. 输入任务名称（可选），以便后续在历史记录中查找。
3. 进度条将显示当前处理进度。

### 第四步：查看结果
1. 分析完成后，结果将显示在右侧的结果查看器中。
2. 点击结果树中的文件，可以展开查看具体的比对结果。
3. 选中某个比对结果，右侧会显示详细信息，包括得分、E-value、覆盖度等。

## 3. 常用功能快捷入口

- **查看历史任务**：点击菜单栏“文件” -> “任务历史记录”。
- **管理数据库**：点击菜单栏“设置” -> “本地数据库管理”。
- **云端加速**：点击菜单栏“设置” -> “云资源管理器”（需要配置 AWS/GCP）。
