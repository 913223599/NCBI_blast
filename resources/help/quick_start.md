# 快速入门指南

欢迎使用 **NCBI Bio-Station** 生物序列分析与基因组全流程工作站。本指南帮助您快速掌握主界面布局与核心分析流程。

## 1. 主界面布局概览
- **左侧主导航栏**：涵盖仪表盘、菌毒种库、基因组拼接、组装分析、BLAST 分析、科研绘图工坊、自动化流水线、设置与帮助九大核心入口，支持一键折叠以扩大图谱视野。
- **顶部信息栏**：提供首页快捷面包屑、运行中任务胶囊、本地 FastAPI 计算服务健康状态指示灯、中/英语言切换以及帮助与设置直达入口。
- **主工作区**：按需懒加载各类生信分析模块，所有表格与结果卡片支持直接划词复制。

## 2. 推荐科研分析路径
1. **原始测序数据拼接**：进入“基因组拼接”，导入双端短读长或三代长读长 FASTQ 文件，系统自动执行 Fastp 质控、NGCS 组装、QUAST 评估与测序深度解析。
2. **深度注释与噬菌体解析**：进入“组装分析”，一键衔接已完成组装任务，依次运行全基因组功能注释、前噬菌体边界发现、噬菌体结构与尾型预测、多样本泛基因组分析及环形/线性图谱浏览。
3. **快速序列鉴定与 16S 多样性**：进入“BLAST 分析”，支持单株 FASTA 比对与 16S 扩增子混样多样性定量分析。
4. **出版级科研出图**：进入“科研绘图工坊”，复用系统注释与比对产物生成高分辨率矢量 PDF/SVG 论文插图。

## 3. 局域网协同共享
在“设置 -> 系统参数”中开启局域网共享后，同网络下的实验成员即可通过浏览器访问工作站；关闭共享时，系统中间件将自动拦截一切非本机回环请求，保障数据安全。
