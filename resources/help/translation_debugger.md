# 翻译调试器

翻译调试器是一个辅助工具，用于测试和优化 AI 翻译功能，确保生物学术语翻译的准确性。

## 访问方式
点击菜单栏 **“设置” -> “翻译调试器”**。

## 功能说明

### 1. 测试翻译
- **输入文本**: 在左侧文本框中输入一段英文生物学描述（例如 BLAST 结果中的 Definition）。
- **执行翻译**: 点击“测试翻译”按钮。
- **查看结果**: 右侧文本框将显示 AI 生成的中文翻译。
- **日志**: 底部日志区域会显示 API 调用的详细信息，包括耗时和可能的错误信息。

### 2. 模型对比
您可以切换不同的 AI 模型（在高级设置中配置），对比它们对同一段文本的翻译效果，从而选择最适合您需求的模型。

### 3. 缓存机制
系统会对翻译结果进行缓存，以减少 API 调用次数和费用。
- 如果输入的文本之前翻译过，系统会直接从缓存中读取结果（日志会显示 "Hit Cache"）。
- 您可以点击“清除缓存”按钮来强制重新调用 API。

## 常见用途
- 验证 API Key 是否有效。
- 测试网络连接是否通畅。
- 评估不同 AI 模型的翻译质量。
- 调试翻译过程中出现的乱码或格式错误。
