# 组装后深度分析工作台指南

组装分析工作台集成了 6 大下游基因组分析模块，支持跨模块结果无缝传递：

## 1. Sanger 测序峰图分析与突变检测
- 直接导入 `.ab1` 峰图文件，可视化四色荧光色谱与 QV 质量值，识别 SNV 与 InDel 重叠峰并执行双单倍型解卷积。

## 2. 全基因组结构与功能注释
- 支持 Prokka、Pharokka、Phold 与 Prodigal 注释流程，内置 CDD/RPS-BLAST 级联补齐假定蛋白注释，生成标准 GBK / GFF3 文件。

## 3. 前噬菌体与噬菌体智能发现
- 采用 Stage 1.2 DNA 底座 + 200bp SubBinRefiner 边界精修及可选蛋白门控，支持超长宿主基因组流式分片扫描与断点续跑，结果可一键下发注释与结构预测。

## 4. 噬菌体结构与尾部形态预测
- 自动识别尾鞘 TSP、MTP、TAP、TTPA/B、Virfam 连接器模块与 TMP 卷尺蛋白标尺，定量判定肌尾、长尾、短尾及非有尾形态。

## 5. 多样本泛基因组比较与序列图谱查看器
- 构建核心/附属/特异基因组谱系、执行鸡尾酒配伍去冗余，并通过 CGView（环形）与 IGV.js（线性）交互式检视全基因组特征。
