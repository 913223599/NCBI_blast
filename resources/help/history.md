# 任务历史记录

系统会自动保存每次 BLAST 分析的任务信息和结果文件，方便您随时回溯和查看。

## 访问方式
点击菜单栏 **“文件” -> “任务历史记录”**。

## 界面功能

### 1. 历史任务列表
左侧显示了按时间排序的任务列表。
- 每个条目包含任务名称（或默认的时间戳名称）和创建时间。
- 状态图标指示任务是成功、失败还是部分完成。

### 2. 任务详情
选中某个任务后，右侧会显示详细信息：
- **任务ID**: 唯一标识符。
- **执行时间**: 任务开始的时间。
- **参数配置**: 当时使用的 BLAST 程序、数据库、E-value 等参数。
- **输入文件**: 参与分析的序列文件列表。

### 3. 操作选项
- **加载结果**: 将该任务的分析结果重新加载到主界面的结果查看器中。
  - 如果主界面已有结果，系统会询问是清空还是追加。
- **打开所在目录**: 在文件资源管理器中打开保存该任务结果的文件夹。
- **删除记录**: 删除选中的历史记录及其对应的结果文件（请谨慎操作）。

## 结果文件结构
每个任务在 `results` 目录下都有一个独立的文件夹，通常包含：
- `*_blast_result.xml`: 详细的 XML 格式结果。
- `*_blast_result.csv`: 表格形式的简要结果。
- `*_blast_result.desc`: 结果描述文本。
- `task_info.json`: 任务元数据文件。

## 提示
- 定期清理旧的任务记录可以释放磁盘空间。
- 您可以手动重命名 `results` 下的任务文件夹，但建议通过软件界面管理以保持数据一致性。
