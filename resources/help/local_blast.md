# 本地 BLAST 分析指南

本地 BLAST 分析是本软件的核心功能，允许您在本地计算机上利用 CPU 资源进行序列比对。

## 支持的程序类型

- **blastn**: 核酸序列比对核酸数据库。适用于寻找同源基因或序列相似性。
- **blastp**: 蛋白质序列比对蛋白质数据库。适用于功能注释和寻找同源蛋白。
- **blastx**: 核酸序列翻译后比对蛋白质数据库。适用于分析编码序列。
- **tblastn**: 蛋白质序列比对翻译后的核酸数据库。
- **tblastx**: 翻译后的核酸序列比对翻译后的核酸数据库。

## 参数详解

### 基础参数
- **数据库 (Database)**: 选择比对的目标数据库。
  - `nt`: 核酸数据库（Nucleotide collection）。
  - `nr`: 非冗余蛋白质数据库（Non-redundant protein sequences）。
  - 自定义数据库：您通过数据库管理器构建的数据库。
- **E-value (期望值)**: 描述随机匹配的概率。值越小，匹配越可信。默认通常为 10 或 0.001。
- **线程数 (Threads)**: 用于计算的 CPU 核心数。增加线程数可以显著加快分析速度，但会占用更多系统资源。

### 高级参数
在“设置”->“高级参数”中可以配置更多选项：
- **输出格式**: 默认生成 XML 和 CSV 格式结果。
- **比对数量限制**: 限制每个查询序列返回的最大比对数。
- **过滤低复杂度区域**: 自动屏蔽低复杂度序列以减少假阳性。

## 结果解读

分析结果包含以下关键指标：
- **Score (得分)**: 比对的原始得分，越高越好。
- **E-value**: 统计学显著性，越低越好（如 0.0 或 1e-100）。
- **Identity (一致性)**: 匹配碱基或氨基酸的百分比。
- **Coverage (覆盖度)**: 查询序列被比对覆盖的比例。
- **Definition**: 目标序列的描述信息。

## 常见问题

**Q: 为什么找不到数据库？**
A: 请确保您已在“本地数据库管理”中正确配置了数据库路径，并且数据库文件完整。

**Q: 分析速度很慢？**
A: 
1. 尝试增加线程数。
2. 确保数据库位于高速硬盘（如 SSD）上。
3. 如果数据量巨大，考虑使用 Elastic BLAST 云服务。
