# 自动化流水线工具指南

“自动化流水线”整合了两套面向日常实验运维的端到端批处理模块：

## 1. 邮件自动收件 -> 注释 -> Word 报告 -> SMTP 回传
- 自动扫描白名单收件箱中的 FASTA 附件，按批次调度基因组注释与 Word 学术报告生成，打包后经预览确认或定时任务经 SMTP 回传发件人。
- 凭证文件（`.mail_auth`）仅保存在本地并被 Git 与 Electron IPC 安全白名单严格隔离。

## 2. 生工 16S 测序结果自动化 BLAST 与导出
- 自动扫描生工测序通知邮件并构建本地订单目录，支持无头浏览器自动下载或本地压缩包导入，自动解压提取序列、批量执行 16S BLAST 比对与物种中文学名翻译，并一键导出标准化 CSV 报表。
