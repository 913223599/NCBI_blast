# NGCS 基因组拼接组装指南

基因组拼接模块面向细菌与噬菌体测序数据，提供从原始读段质控到环状染色体评估的自动化串行流水线。

## 1. 支持的数据类型
- **二代短读长（Illumina / MGI）**：支持成对 `R1/R2` `.fastq` / `.fastq.gz` 或打包 `.zip` 文件。
- **三代长读长（Nanopore / PacBio）**：支持单端长读长 FASTQ 文件与混合组装模式。

## 2. 流水线阶段
1. **Fastp 质控清洗**：自动切除测序接头、过滤低质量碱基并生成质控指标。
2. **NGCS 核心组装与打磨**：自动路由至对应组装引擎，执行拓扑成环检测与断点修复。
3. **QUAST 与深度统计**：计算 Contig 数量、总长度、N50、L50、GC 含量及加权平均测序深度。

## 3. 队列与硬件保护
- 任务提交后进入持久化串行队列 (`max_workers=1`)，确保同一时刻仅运行一个重负载组装任务，防止内存耗尽或主机卡死。
- 完成后可直接导出 FASTA 序列或一键跳转至“组装分析工作台”进行注释。
