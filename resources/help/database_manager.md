# 本地数据库管理

数据库管理器允许您下载 NCBI 官方数据库或从本地 FASTA 文件构建自定义数据库。

## 访问方式
点击菜单栏 **“设置” -> “本地数据库管理”**。

## 功能模块

### 1. 数据库列表
左侧列表显示了当前已配置的所有本地数据库。
- **名称**: 数据库的简短标识符（如 `nt`, `refseq_rna`）。
- **路径**: 数据库文件在磁盘上的位置。
- **类型**: 核酸 (Nucleotide) 或 蛋白质 (Protein)。

### 2. 添加现有数据库
如果您已经下载了 BLAST 数据库文件：
1. 点击“添加数据库”。
2. 浏览并选择数据库的主文件（通常没有扩展名，或以 `.nal` / `.pal` 结尾）。
3. 输入一个易于识别的名称。

### 3. 构建新数据库 (Makeblastdb)
从 FASTA 序列文件创建 BLAST 数据库：
1. 切换到“构建数据库”选项卡。
2. **输入文件**: 选择您的 FASTA 格式序列文件。
3. **数据库类型**: 选择是核酸还是蛋白质。
4. **输出名称**: 设置生成的数据库名称。
5. **输出目录**: 选择保存位置。
6. 点击“构建”按钮。

### 4. 下载 NCBI 数据库
直接从 NCBI 服务器下载常用数据库：
1. 切换到“下载数据库”选项卡。
2. 从列表中选择需要下载的数据库（如 `16S_ribosomal_RNA`, `swissprot`）。
3. 点击“下载”。
4. **注意**: `nt` 和 `nr` 数据库非常大（数百 GB），下载和解压需要较长时间和大量磁盘空间。

## 数据库维护
- **删除**: 选中列表中的数据库，点击“删除”将其从配置中移除（不会删除物理文件）。
- **验证**: 系统会自动检查数据库文件是否完整。

## 提示
- 建议将数据库存放在 SSD 固态硬盘上以获得最佳性能。
- 定期更新数据库以获取最新的生物序列信息。
