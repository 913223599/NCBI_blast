# 科研绘图工坊指南

科研绘图工坊对标顶刊插图标准，直接复用系统内的注释与进化分析产物，支持矢量 **PDF / SVG** 与高清 **PNG** 导出。

## 内置 7 大图型工具
1. **系统发育树构建与多环出版出图**：支持 MAFFT/Muscle 比对与 FastTree/IQ-TREE 构树，提供环形多环、180 度半圆宽幅、复合双拼与矩形多轨样式。
2. **VIRIDIC 双向相似性与 ANI 矩阵**：输出 ICTV 标准双三角热图（相似度 + 对齐覆盖度 + 基因组长度柱图）。
3. **单株全基因组功能圈图与多轨图**：一键载入 GBK 注释产物，展示正负链 CDS、PHROGs 功能色、GC Content 与 GC Skew。
4. **比较基因组共线性丝带图**：支持 LoVis4u 去噪高亮风格与 clinker 贝塞尔丝带风格。
5. **同种多株系核苷酸多样性 (Pi) 热点图**：滑窗 Pi 曲线结合基因内部热图定位高变受体蛋白热点。
6. **蛋白基因共享网络与构成华夫格图**：力导向网络结合 10x10 类别占比华夫格图。
7. **双树联动宿主谱与特异性矩阵**：支撑噬菌体宿主谱与鸡尾酒配伍发表。
