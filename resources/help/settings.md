# 参数与设置

本软件提供了丰富的配置选项，以满足不同场景下的分析需求。

## 基础参数 (主界面)

这些参数位于主界面的左侧侧边栏，是每次分析最常用的设置。

- **程序 (Program)**: 选择 BLAST 的具体程序，如 `blastn`, `blastp`。
- **数据库 (Database)**: 选择比对的目标数据库。
- **E-value**: 统计显著性阈值。
- **线程数 (Threads)**: 并行计算的 CPU 核心数。

## 高级参数

通过菜单栏 **“设置” -> “高级参数”** 打开。

### 1. BLAST 高级选项
- **Word Size**: 初始匹配的种子词长度。
- **Gap Costs**: 空位罚分。
- **Matrix**: 氨基酸替换矩阵（如 BLOSUM62）。
- **Filter Low Complexity**: 开启或关闭低复杂度区域过滤。

### 2. AI 翻译设置
- **启用 AI 翻译**: 自动将 BLAST 结果中的英文描述翻译成中文。
- **翻译服务商**: 选择使用的翻译引擎（如 DeepSeek, DashScope 等）。
- **AI 模型**: 选择具体的翻译模型。

### 3. Elastic BLAST 设置
- **启用 Elastic BLAST**: 将计算任务提交到云端执行。
- **云提供商**: AWS 或 GCP。
- **区域 (Region)**: 云服务器所在的地理位置。
- **结果存储桶**: 用于存储云端结果的 S3 或 GCS 存储桶地址。

## API 密钥管理

通过菜单栏 **“帮助” -> “API 密钥”** 打开。

- 用于配置 AI 翻译服务所需的 API Key。
- 选择服务商，将您的密钥粘贴到输入框中，然后点击“保存”。
- 密钥将安全地存储在本地配置文件中。

## 配置文件
所有设置都保存在项目根目录下的 `config.json` 文件中。您可以手动编辑此文件，但建议通过软件界面修改以避免格式错误。
