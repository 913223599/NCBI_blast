Tool: xml_print.exe
========================================

Find an XML context matching query and print values as a .tsv-file

USAGE:   xml_print.exe <in> <out> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    xml_print.exe -help
VERSION: xml_print.exe -version

POSITIONAL PARAMETERS
<in>
    Input XML file
<out>
    Output XML file

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
