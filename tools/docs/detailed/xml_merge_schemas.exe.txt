Tool: xml_merge_schemas.exe
========================================

Merge XML schemas

USAGE:   xml_merge_schemas.exe <xml_list> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    xml_merge_schemas.exe -help
VERSION: xml_merge_schemas.exe -version

POSITIONAL PARAMETERS
<xml_list>
    List of XML schemas of the same tag, outputs of xml2schema

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
