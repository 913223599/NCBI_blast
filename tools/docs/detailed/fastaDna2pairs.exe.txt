Tool: fastaDna2pairs.exe
========================================

Print a DNA multi-fasta file as pairs: <id> <sequence>

USAGE:   fastaDna2pairs.exe <in> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    fastaDna2pairs.exe -help
VERSION: fastaDna2pairs.exe -version

POSITIONAL PARAMETERS
<in>
    Input multi-fasta file with DNA sequences

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
