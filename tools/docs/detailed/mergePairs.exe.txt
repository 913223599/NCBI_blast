Tool: mergePairs.exe
========================================

Merge pairs with identical first element:
A1	B1
A1	B2
A2	B3
A4	B4
->
A1	B1	B2
A2	B3	B4

USAGE:   mergePairs.exe <in> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    mergePairs.exe -help
VERSION: mergePairs.exe -version

POSITIONAL PARAMETERS
<in>
    Input file

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
