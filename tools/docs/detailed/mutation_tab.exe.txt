Tool: mutation_tab.exe
========================================

Print mutations table in a tab-delimited fromat

USAGE:   mutation_tab.exe <blastp> <ref_accession> <metadata_headers> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    mutation_tab.exe -help
VERSION: mutation_tab.exe -version

POSITIONAL PARAMETERS
<blastp>
    blastp output in the format: qseqid qseq sseq. qseqid has format: accession|.... Sequences should have flanking stop codons
<ref_accession>
    Accession of the reference protein
<metadata_headers>
    Column names for metadata, separated by '|'

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
