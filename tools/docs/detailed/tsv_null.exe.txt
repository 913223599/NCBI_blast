Tool: tsv_null.exe
========================================

Replace "NA" etc. by "" in a .tsv-file and print

USAGE:   tsv_null.exe <table> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    tsv_null.exe -help
VERSION: tsv_null.exe -version

POSITIONAL PARAMETERS
<table>
    tsv-table

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
