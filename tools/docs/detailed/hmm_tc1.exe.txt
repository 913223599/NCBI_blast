Tool: hmm_tc1.exe
========================================

Find TC1 for an HMM

USAGE:   hmm_tc1.exe [-hmmsearch ""] [-error_max 0] [-seqFName ""] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    hmm_tc1.exe -help
VERSION: hmm_tc1.exe -version

NAMED PARAMETERS
-hmmsearch ""
    Output of hmmsearch of <seqFName> against one HMM
-error_max 0
    Max. error fraction w.r.t. seeds to be "good"
-seqFName ""
    File with seed protein sequences
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
