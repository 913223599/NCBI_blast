Tool: feature2dissim.exe
========================================

Convert feature sets to dissimilarities (Hamming distance, Jaccard index) "dissim" and print a .dm-file

USAGE:   feature2dissim.exe <objects> <dir> [-optional_weight NaN] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    feature2dissim.exe -help
VERSION: feature2dissim.exe -version

POSITIONAL PARAMETERS
<objects>
    File with a list of object files with features
<dir>
    Directory with <object> files containing feature-optional(0/1) pairs

NAMED PARAMETERS
-optional_weight NaN
    Weight of optional-nonoptional match (0..1) - for Hamming distance
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
