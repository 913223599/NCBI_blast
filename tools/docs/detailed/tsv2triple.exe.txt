Tool: tsv2triple.exe
========================================

Convert a tsv-file into an object-attribute-value table

USAGE:   tsv2triple.exe <tsv> [-keys ""] [-file_name_key] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    tsv2triple.exe -help
VERSION: tsv2triple.exe -version

POSITIONAL PARAMETERS
<tsv>
    tsv-table

NAMED PARAMETERS
-keys ""
    Object columns in <tsv>, comma-delimited
-file_name_key
    File name without extension should be added as the last key
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
