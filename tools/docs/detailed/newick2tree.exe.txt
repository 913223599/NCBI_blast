Tool: newick2tree.exe
========================================

Print a tree

USAGE:   newick2tree.exe <input_tree> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    newick2tree.exe -help
VERSION: newick2tree.exe -version

POSITIONAL PARAMETERS
<input_tree>
    Tree in Newick format

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
