Tool: dna_align_service.exe
========================================

DNA alignment service

USAGE:   dna_align_service.exe <dna_align> <query_dir> [-quiet] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-threads 1] [-json ""] [-log ""] [-sigpipe]
HELP:    dna_align_service.exe -help
VERSION: dna_align_service.exe -version

POSITIONAL PARAMETERS
<dna_align>
    File with DNA alignment: <# sequences> <sequence length><EOL>{<sequence name> <space>+ <DNA sequence>}+
<query_dir>
    Directory with queries:
<file>.dissim: <input file> <nl> <output file> <nl> END
<file>.closest: <object> <nl> <search objects> <nl> <output file> <nl> END

NAMED PARAMETERS
-quiet
    Quiet
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-threads 1
    Max. number of threads
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
