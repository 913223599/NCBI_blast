Tool: dna_diff.exe
========================================

Print the number of nucleotide differences between two DNA sequences, case-insensitive

USAGE:   dna_diff.exe <in> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    dna_diff.exe -help
VERSION: dna_diff.exe -version

POSITIONAL PARAMETERS
<in>
    Input file with two DNA sequences

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
