Tool: tsv_rename.exe
========================================

Print a tsv-table with a renamed column

USAGE:   tsv_rename.exe <tsv> <col_num> <col_name> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    tsv_rename.exe -help
VERSION: tsv_rename.exe -version

POSITIONAL PARAMETERS
<tsv>
    tsv-file name
<col_num>
    1-based column number
<col_name>
    New column name

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
