Tool: tree2indiscern.exe
========================================

Print indiscernibility clusters of a distance tree: <object> <cluster leading object>

USAGE:   tree2indiscern.exe <input_tree> [-discern] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    tree2indiscern.exe -help
VERSION: tree2indiscern.exe -version

POSITIONAL PARAMETERS
<input_tree>
    File with the tree and arc lengths

NAMED PARAMETERS
-discern
    Print discernible objects
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
