Tool: fasta2feature.exe
========================================

Save position-based features of an alignment

USAGE:   fasta2feature.exe <Multi_FASTA> <out_dir> [-aa] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    fasta2feature.exe -help
VERSION: fasta2feature.exe -version

POSITIONAL PARAMETERS
<Multi_FASTA>
    Multi-FASTA file
<out_dir>
    Output directory

NAMED PARAMETERS
-aa
    Multi-FASTA file contains protein sequences, otherwise DNA sequences
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
