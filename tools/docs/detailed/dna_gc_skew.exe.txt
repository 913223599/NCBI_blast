Tool: dna_gc_skew.exe
========================================

DNA GC skew (G - C) / (G + C) distribution

USAGE:   dna_gc_skew.exe <in> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    dna_gc_skew.exe -help
VERSION: dna_gc_skew.exe -version

POSITIONAL PARAMETERS
<in>
    Input FASTA file with a DNA sequence

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
