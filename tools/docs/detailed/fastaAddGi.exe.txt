Tool: fastaAddGi.exe
========================================

Create a FASTA file <fasta>.out where each identifier is prepended by a new gi starting from <min_gi>

USAGE:   fastaAddGi.exe <fasta> <min_gi> [-aa] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    fastaAddGi.exe -help
VERSION: fastaAddGi.exe -version

POSITIONAL PARAMETERS
<fasta>
    Input FASTA file
<min_gi>
    Min. gi

NAMED PARAMETERS
-aa
    Amino acid sequence, otherwise nucleotide
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
