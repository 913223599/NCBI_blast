Tool: kmerIndex_stat.exe
========================================

Print statsitics of DNA k-mer index

USAGE:   kmerIndex_stat.exe <kmer_index> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    kmerIndex_stat.exe -help
VERSION: kmerIndex_stat.exe -version

POSITIONAL PARAMETERS
<kmer_index>
    DNA k-mer index file name

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
