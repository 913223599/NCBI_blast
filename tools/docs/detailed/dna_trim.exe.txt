Tool: dna_trim.exe
========================================

Update a DNA sequence by trimming head and tail

USAGE:   dna_trim.exe <in> <head> <tail> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    dna_trim.exe -help
VERSION: dna_trim.exe -version

POSITIONAL PARAMETERS
<in>
    DNA FASTA file with a DNA sequence
<head>
    Head length
<tail>
    Tail length

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
