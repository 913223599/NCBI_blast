Tool: feature2gain_loss.exe
========================================

Print gains and losses of one feature in a tree

USAGE:   feature2gain_loss.exe <input_tree> <feature> [-prefer_gain] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    feature2gain_loss.exe -help
VERSION: feature2gain_loss.exe -version

POSITIONAL PARAMETERS
<input_tree>
    Input file with the tree
<feature>
    Input file with genome list

NAMED PARAMETERS
-prefer_gain
    Prefer gain over loss in maximum parsimony method
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
