Tool: mutation2feature.exe
========================================

Convert mutations to 3-valued Boolean attributes of non-ambiguous mutations for makeFeatureTree

USAGE:   mutation2feature.exe <in> <feature_dir> [-aa] [-append] [-large] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    mutation2feature.exe -help
VERSION: mutation2feature.exe -version

POSITIONAL PARAMETERS
<in>
    Input directory with DNA mutations in the format <ref seq><ref pos><target seq>
<feature_dir>
    Output directory for 3-valued Boolean atrtributes for makeFeatrueTree

NAMED PARAMETERS
-aa
    Mutations of protein sequences, otherwise of DNA sequences
-append
    Append existing files in <feature_dir>
-large
    Create files in subdirectories "0" .. "999" which are the hashes of file names
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
