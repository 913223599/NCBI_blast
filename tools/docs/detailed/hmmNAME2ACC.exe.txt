Tool: hmmNAME2ACC.exe
========================================

Add ACC=NAME in an HMM library

USAGE:   hmmNAME2ACC.exe <in> <out> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    hmmNAME2ACC.exe -help
VERSION: hmmNAME2ACC.exe -version

POSITIONAL PARAMETERS
<in>
    Input NCBI HMM library
<out>
    Output NCBI HMM library

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
