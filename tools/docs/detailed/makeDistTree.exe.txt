Tool: makeDistTree.exe
========================================

## 项目中的使用说明 (Source Code Context)
在本项目 (`src/tree/tree_executor.py`) 中，`makeDistTree` 用于从距离矩阵 (.dm) 构建系统发育树。

**典型调用方式**:
```python
makeDistTree.exe -data <DATA_BASE_PATH> -variance lin -output_tree <OUTPUT_NWK>
```

**常见问题与技巧**:
- **-data 参数**: 必须传入不带 `.dm` 后缀的基础路径。如果文件是 `file.dm`，则 `-data file`。
- **-variance lin**: 使用线性方差模型 (Linear Variance) 构建树。
- 输入必须是先前由 `fasta2dissim` 生成的矩阵文件。
