Tool: list2pairs.exe
========================================

Print the pairs of words from a list. In each pair: word1 < word2

USAGE:   list2pairs.exe <list> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    list2pairs.exe -help
VERSION: list2pairs.exe -version

POSITIONAL PARAMETERS
<list>
    File with different words

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
