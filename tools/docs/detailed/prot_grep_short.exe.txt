Tool: prot_grep_short.exe
========================================

Find proteins in <short> which are substrings of proteins in <in>

USAGE:   prot_grep_short.exe <in> <short> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    prot_grep_short.exe -help
VERSION: prot_grep_short.exe -version

POSITIONAL PARAMETERS
<in>
    FASTA file with all proteins
<short>
    FASTA file with short proteins

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
