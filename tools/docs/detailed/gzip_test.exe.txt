Tool: gzip_test.exe
========================================

Test

USAGE:   gzip_test.exe <arg> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    gzip_test.exe -help
VERSION: gzip_test.exe -version

POSITIONAL PARAMETERS
<arg>
    Argument

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
