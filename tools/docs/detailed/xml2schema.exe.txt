Tool: xml2schema.exe
========================================

Analyze an XML file and print the derived schema

USAGE:   xml2schema.exe <xml> [-no_xml_header] [-print ""] [-store_values] [-js] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    xml2schema.exe -help
VERSION: xml2schema.exe -version

POSITIONAL PARAMETERS
<xml>
    XML file

NAMED PARAMETERS
-no_xml_header
    XML file has no header
-print ""
    Output XML file
-store_values
    Store all field values in schema
-js
    <xml> is Json
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
