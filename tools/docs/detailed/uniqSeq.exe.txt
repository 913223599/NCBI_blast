Tool: uniqSeq.exe
========================================

Print unique sequences

USAGE:   uniqSeq.exe <in> [-aa] [-pair ""] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    uniqSeq.exe -help
VERSION: uniqSeq.exe -version

POSITIONAL PARAMETERS
<in>
    Input FASTA file

NAMED PARAMETERS
-aa
    Sequences are proteins, otherwise DNA
-pair ""
    Output file of replacement id pairs: <redundant id> <tab> <main id>
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
