Tool: seq_print.exe
========================================

Print a sequence with spacing

USAGE:   seq_print.exe <in> [-aa] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    seq_print.exe -help
VERSION: seq_print.exe -version

POSITIONAL PARAMETERS
<in>
    Input DNA multi-FASTA file

NAMED PARAMETERS
-aa
    Sequence is a protein, otherwise DNA
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
