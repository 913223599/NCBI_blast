Tool: blastmat.exe
========================================

Convert a BLAST similarity matrix to a distance matrix, analyze

USAGE:   blastmat.exe <mat> <gap> <gap_open> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    blastmat.exe -help
VERSION: blastmat.exe -version

POSITIONAL PARAMETERS
<mat>
    File with a BLAST score matrix
<gap>
    Gap cost, >= 0
<gap_open>
    Gap open cost, >= 0

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
