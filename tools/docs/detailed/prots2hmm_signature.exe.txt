Tool: prots2hmm_signature.exe
========================================

Print HMM signature for each protein

USAGE:   prots2hmm_signature.exe <hmmsearch> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    prots2hmm_signature.exe -help
VERSION: prots2hmm_signature.exe -version

POSITIONAL PARAMETERS
<hmmsearch>
    Output of hmmsearch

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
