Tool: prot_find.exe
========================================

Print protein sequence closest to a target

USAGE:   prot_find.exe <in> <target> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    prot_find.exe -help
VERSION: prot_find.exe -version

POSITIONAL PARAMETERS
<in>
    Multi-FASTA file with proteins
<target>
    FASTA file with a target protein

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
