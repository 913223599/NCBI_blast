Tool: multilist2subset.exe
========================================

Print the top N different items

USAGE:   multilist2subset.exe <list> <subset> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    multilist2subset.exe -help
VERSION: multilist2subset.exe -version

POSITIONAL PARAMETERS
<list>
    List with possible duplications
<subset>
    Number of items to print

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
