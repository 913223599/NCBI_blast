Tool: makeFeatureTree.exe
========================================

Optimize a feature tree

USAGE:   makeFeatureTree.exe [-input_tree ""] [-features ""] [-large] [-input_core ""] [-nominal_singleton_is_optional] [-prefer_gain] [-use_time] [-optim_iter_max 0] [-save_mem] [-output_core ""] [-output_tree ""] [-newick ""] [-min_newick_name] [-qual ""] [-qual_nonredundant] [-gain_nodes ""] [-loss_nodes ""] [-gain_loss_leaves] [-disagreement_nodes ""] [-arc_length_stat ""] [-patr_dist ""] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-threads 1] [-json ""] [-log ""] [-sigpipe]
HELP:    makeFeatureTree.exe -help
VERSION: makeFeatureTree.exe -version

NAMED PARAMETERS
-input_tree ""
    Input file with the tree
-features ""
    Input directory with features for each genome. Line format: {{<Boolean attribute> [<optional (0|1)>]} | {<nominal attribute>:<value>} \n}*, where <value> = _OTHER_ means a singleton Boolean attribute
-large
    Featrue files are grouped into subdirectories which are their hash-names (hash<string> % 1000)
-input_core ""
    Input file with root core feature ids
-nominal_singleton_is_optional
    Nominal singleton value means that all values of this nominal attribute are optional for the genome
-prefer_gain
    Prefer gain over loss in maximum parsimony method
-use_time
    Use time for MLE, otherwise maximum parsimony method
-optim_iter_max 0
    # Iterations for tree optimization; -1: optimize time only
-save_mem
    Save RAM memory by processing features one by one in the tree. This makes processing slower and restricts functionality
-output_core ""
    Find root, set root core, sort tree and save file with root core feature ids
-output_tree ""
    Output file with the tree
-newick ""
    Output file with the tree in the Newick format
-min_newick_name
    Minimal leaf names in Newick
-qual ""
    Print the summary gain/loss statistics measured by feature consistency, save gain/loss statistics for non-singleton features in the indicated tsv-file
-qual_nonredundant
    Non-redundify features by removing identical ones for the summary gain/loss statistics
-gain_nodes ""
    File name to save nodes where features are gained; within a node features are ordered alphabetically
-loss_nodes ""
    File name to save nodes where features are lost; within a node features are ordered alphabetically
-gain_loss_leaves
    Add number of leaves for node-feature gain or loss
-disagreement_nodes ""
    File name to save nodes with features not gained monophyletically
-arc_length_stat ""
    File with arc length statistics in format <node name> <arc length> <depth length> <log(<parent arc length>/<arc length>)
-patr_dist ""
    File with patristic distances in format: <leaf name1> <leaf name2> <distance>, where <leaf name1> < <leaf name2>
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-threads 1
    Max. number of threads
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
