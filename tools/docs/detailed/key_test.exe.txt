Tool: key_test.exe
========================================

key_test

USAGE:   key_test.exe <go> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    key_test.exe -help
VERSION: key_test.exe -version

POSITIONAL PARAMETERS
<go>
    Print key codes after pressing <Enter>. 'q' exits

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
