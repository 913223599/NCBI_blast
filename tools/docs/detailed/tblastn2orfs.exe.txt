Tool: tblastn2orfs.exe
========================================

Find best annotation and print proteins

USAGE:   tblastn2orfs.exe <dna> <tblastn> <gencode> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    tblastn2orfs.exe -help
VERSION: tblastn2orfs.exe -version

POSITIONAL PARAMETERS
<dna>
    DNA multi-FASTA file used for TBLASTN
<tblastn>
    tblastn output in format: qseqid sseqid length positive qstart qend sstart send slen sseq
<gencode>
    Genetic code

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
