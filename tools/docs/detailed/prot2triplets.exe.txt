Tool: prot2triplets.exe
========================================

AA tiplet statistics. Create file "short" with short proteins

USAGE:   prot2triplets.exe <in> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    prot2triplets.exe -help
VERSION: prot2triplets.exe -version

POSITIONAL PARAMETERS
<in>
    Input FASTA file of proteins

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
