Tool: mlst2hash.exe
========================================

Print 64-bit MLST hashes

USAGE:   mlst2hash.exe <loci> <blastn> <out> [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    mlst2hash.exe -help
VERSION: mlst2hash.exe -version

POSITIONAL PARAMETERS
<loci>
    Number of MLST loci
<blastn>
    BLASTN output in the format: qseqid sseq
<out>
    Output file with 64-bit MLST hash, or "NONE" if type cannot be computed

NAMED PARAMETERS
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
