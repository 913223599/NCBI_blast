Tool: dna2stat.exe
========================================

Compute statistics for a DNA multi-FASTA file: length, ambiguities fraction, GC fraction, octamers fraction

USAGE:   dna2stat.exe <in> [-acgt] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    dna2stat.exe -help
VERSION: dna2stat.exe -version

POSITIONAL PARAMETERS
<in>
    Input DNA multi-FASTA file

NAMED PARAMETERS
-acgt
    Add A, C, G and T fractions
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
