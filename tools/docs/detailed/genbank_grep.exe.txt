Tool: genbank_grep.exe
========================================

Print accession numbers of the sequence GenBank records containing a keyword

USAGE:   genbank_grep.exe <in> <keyword> [-field ""] [-qc] [-verbose 0] [-noprogress] [-profile] [-seed 1] [-json ""] [-log ""] [-sigpipe]
HELP:    genbank_grep.exe -help
VERSION: genbank_grep.exe -version

POSITIONAL PARAMETERS
<in>
    Genbank file
<keyword>
    Keyword to find (case-insensitive)

NAMED PARAMETERS
-field ""
    Field name
-qc
    Integrity checks (quality control)
-verbose 0
    Level of verbosity
-noprogress
    Turn off progress printout
-profile
    Use chronometers to profile
-seed 1
    Positive integer seed for random number generator
-json ""
    Output file in Json format
-log ""
    Error log file, appended
-sigpipe
    Exit normally on SIGPIPE
