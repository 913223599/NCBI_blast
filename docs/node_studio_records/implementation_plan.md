# Bio-Node Studio: 节点化生物信息学分析工作坊

受 Unreal Engine (Blueprints) 和 Unity (Shader Graph) 启发，我们将分析流程从固定的“电路布局”升级为完全自由、可扩展的**节点式可视化流转系统**。

## 术语规范化 (Professional & Engine-Style)

为了保持专业感与功能性的平衡，我们定义以下术语：

| 引擎概念 (Engine Concept) | 描述 (Description) |
| :--- | :--- |
| **画布 (Canvas)** | 支持缩放、平移的无限工作空间。 |
| **分析节点 (Node)** | 封装特定功能的卡片，包含参数配置区。 |
| **输入/输出端口 (Pins)** | 节点两侧的连接点，代表数据进出口。 |
| **连线 (Edges/Wires)** | 具有方向性的贝塞尔曲线，代表数据流向。 |
| **执行序列 (Pipeline)** | 由节点连接构成的有向无环图 (DAG)。 |

## 核心功能设计

### 1. 动态节点架构 (Dynamic Node Architecture)
每个节点不再是一个简单的图标，而是一个具有完整内部逻辑的卡片：
- **Header**: 显示节点类型（如 `FASTA Reader`, `NJ Tree Builder`）。
- **Body**: 嵌入式 UI 控件，用户可直接在画布上修改参数（如 K-mer Size, Threads）。
- **Pins**: 左侧为输入（如 `Matrix Input`），右侧为输出（如 `Tree Topology`）。

### 2. 自由连线系统 (Free-Wiring System)
- **手柄交互**：用户点击并拖拽输出端口，在合适的目标输入端口上松开以建立连接。
- **类型校验**：系统会自动识别端口数据类型（如不可将 FASTA 输出连接到 Tree 输入），并在连接时提供视觉反馈。
- **路径优化**：连线采用平滑的贝塞尔曲线，自动避开节点主体。

### 3. 后端拓扑调度 (DAG Execution)
- **依赖追踪**：后端根据节点连接关系自动生成执行序列。
- **延迟执行**：修改上游参数后，下游受影响的连线将进入“待刷新”颗粒态。
- **分阶段缓存**：每个节点的输出结果将被临时缓存，避免重复计算。

## 实施阶段

### 第一阶段：画布基座开发 (已完成)
- 实现基于 SVG/HTML5 Canvas 的缩放平移背景。
- 开发万能节点容器（Node Shell），支持属性列表渲染。

### 第二阶段：连线与逻辑绑定
- 实现点击、拖拽生成 Bezier 连线的交互。
- 建立前端节点 ID 映射表，支持 `py_bridge` 传输完整的 JSON 拓扑结构。

### 第三阶段：动态库集成
- 建立分析工具库 (Node Library)，支持从侧边栏将新工具拖入画布。
- **分类架构**：支持 I/O、Processing、Analysis 等三层专业化分类，方便后期扩展百量级分析插件。

## 架构可扩展性保证 (Future-Proofing)
- **动态注册**：后端采用配置驱动模式。新增一个工具只需在 `tool_config.py` 中注册其路径和参数 Schema，前端画布即可自动生成其对应的节点 UI。

## 验证计划
- **DAG 解析验证**：确保复杂的节点连接网络能够正确转换为 Python 执行队列。
- **UI 压力测试**：在画布上部署 50+ 节点时依然保持交互流畅。
